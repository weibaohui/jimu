# 插件管理前端界面 - 快速演示

## 启动步骤

### 1. 启动后端服务

```bash
cd host/backend
cargo run
```

后端将在 `http://localhost:3000` 启动。

### 2. 启动前端服务

```bash
cd host/frontend
npm install  # 首次运行需要安装依赖
npm run dev
```

前端将在 `http://localhost:5173` 启动。

### 3. 访问界面

在浏览器中打开 `http://localhost:5173`

## 演示流程

### 第一步：查看仪表盘

1. 访问 `http://localhost:5173/dashboard`
2. 查看插件统计概览
3. 查看最近更新的插件列表

### 第二步：上传插件

1. 点击左侧菜单的"插件管理"
2. 点击"上传插件"按钮
3. 选择上传方式：
   - **文件上传**：选择 `plugins/user-management/user-management.plugin` 文件
   - 或使用其他上传方式
4. 点击"上传"

### 第三步：管理插件

在插件列表中，你可以：

1. **查看插件状态**：看到插件的状态标签
2. **启用插件**：点击"启用"按钮
3. **启动插件**：启用后，点击"启动"按钮
4. **查看详情**：点击"详情"按钮，查看插件详细信息

### 第四步：查看插件详情

在插件详情页面，有三个标签：

1. **基本信息**
   - 查看插件的名称、版本、描述、作者
   - 查看当前状态
   - 查看创建和更新时间
   - 查看依赖信息

2. **运行日志**
   - 查看插件的运行日志
   - 点击"开启自动刷新"实时查看日志
   - 点击"清空日志"清空所有日志

3. **沙盒统计**
   - 查看内存使用情况
   - 查看 CPU 时间使用情况
   - 查看操作次数
   - 查看违规记录（如果有）

### 第五步：插件操作

1. **重载插件**：在插件列表或详情页面，点击"重载"按钮进行热重载
2. **停止插件**：点击"停止"按钮停止运行中的插件
3. **禁用插件**：点击"禁用"按钮禁用插件
4. **卸载插件**：点击"卸载"按钮卸载插件（需要确认）

### 第六步：系统设置

1. 点击插件管理页面的"系统设置"标签
2. 配置自动重载
3. 设置资源限制
4. 配置日志管理
5. 查看系统信息

## 界面预览

### 仪表盘
- 显示插件总数、运行中、已启用、已禁用的统计
- 显示最近更新的5个插件

### 插件列表
- 表格形式显示所有插件
- 每行显示插件名称、描述、作者、状态、操作
- 顶部显示统计卡片
- 支持分页

### 插件详情
- 抽屉式详情面板
- 三个标签页：基本信息、运行日志、沙盒统计
- 支持自动刷新
- 显示详细的上下文信息

### 插件上传
- 模态对话框
- 三个标签页：文件上传、服务器路径、Base64 数据
- 表单验证

### 系统设置
- 表单式配置界面
- 自动重载开关
- 资源限制设置
- 日志管理配置
- 系统信息展示

## 插件状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|-----------|
| 未安装 | 插件未安装 | - |
| 已安装 | 插件已安装但未启用 | 启用、卸载 |
| 已启用 | 插件已启用但未启动 | 启动、禁用、卸载 |
| 已禁用 | 插件已被禁用 | 启用、卸载 |
| 运行中 | 插件正在运行 | 停止、重载、禁用 |
| 已停止 | 插件已停止 | 启动、禁用、卸载 |
| 加载中 | 插件正在加载 | - |
| 卸载中 | 插件正在卸载 | - |
| 错误 | 插件发生错误 | 重载、卸载 |

## 常见操作

### 如何上传新插件？
1. 点击"上传插件"按钮
2. 选择上传方式（文件/路径/Base64）
3. 填写必要信息
4. 点击"上传"

### 如何启用并启动插件？
1. 在插件列表中找到目标插件
2. 点击"启用"按钮
3. 等待状态变为"已启用"
4. 点击"启动"按钮
5. 等待状态变为"运行中"

### 如何查看插件日志？
1. 点击插件的"详情"按钮
2. 切换到"运行日志"标签
3. 点击"开启自动刷新"实时查看
4. 或手动点击"刷新日志"

### 如何查看沙盒资源使用？
1. 点击插件的"详情"按钮
2. 切换到"沙盒统计"标签
3. 查看内存和CPU使用情况
4. 查看违规记录

### 如何重载插件？
1. 在插件列表或详情页面
2. 点击"重载"按钮
3. 等待重载完成
4. 插件会自动恢复运行

### 如何卸载插件？
1. 在插件列表中找到目标插件
2. 点击"卸载"按钮
3. 在确认对话框中点击"确定"
4. 等待卸载完成

## 技术细节

### 前端技术栈
- React 18
- TypeScript 5
- Ant Design 5
- React Router 6
- Axios

### API 通信
- 所有 API 请求使用 axios
- 统一的错误处理
- 请求和响应拦截器
- 超时设置（10秒）

### 状态管理
- 使用 React Hooks
- Context API 用于菜单管理
- 组件本地状态

### 自动刷新
- 日志和沙盒统计支持自动刷新
- 默认每3秒刷新一次
- 可手动开关

### 响应式设计
- 使用 Ant Design 的栅格系统
- 支持不同屏幕尺寸
- 移动端适配

## 故障排除

### 前端无法启动
- 检查 Node.js 版本（需要 14+）
- 删除 `node_modules` 重新安装
- 检查端口 5173 是否被占用

### 无法连接后端
- 检查后端服务是否启动
- 检查后端端口（默认 3000）
- 检查 CORS 配置
- 查看浏览器控制台错误

### 插件上传失败
- 检查 .plugin 文件格式
- 检查文件大小
- 查看后端日志
- 检查文件权限

### 自动刷新不工作
- 检查网络连接
- 检查后端服务是否正常
- 查看浏览器控制台错误
- 尝试手动刷新
