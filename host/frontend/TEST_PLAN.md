# 前端界面测试计划

## 测试准备

### 环境要求
- Node.js 14+
- Rust 1.70+
- 现代浏览器（Chrome/Firefox/Edge/Safari）

### 启动服务
```bash
# 终端1：启动后端
cd host/backend
cargo run

# 终端2：启动前端
cd host/frontend
npm install  # 首次运行
npm run dev
```

### 访问地址
- 前端：http://localhost:5173
- 后端：http://localhost:3000
